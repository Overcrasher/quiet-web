Quiet Web

Say no to the noise

Quiet Web is a free Chrome extension that says no to cookie banners and closes newsletter popups for you, so pages stay readable. It always picks the privacy-friendly option, and it never clicks Accept.

Coming soon to the Chrome Web Store

Free, no ads, no accounts. Works in Chrome.

How it works

  1. Banners answered with noQuiet Web recognises the most common consent platforms and clicks "reject all" or saves only the necessary cookies. If it can find nothing safer to click, it hides the banner and counts that case separately.
  2. Newsletter popups closedPopups that cover much of a page and ask for your email are closed, and scrolling is restored. It never acts on login, sign-up, checkout, cart, payment or account pages.
  3. See it, and switch it off per siteThe popup shows how many annoyances were handled and what happened on the current site. If a site looks broken, switch Quiet Web off for it, or open a prefilled GitHub issue. Nothing is sent automatically.

Why it needs access to all sites

Cookie banners appear on every kind of website, so Quiet Web has to look at pages to find them. It does this on your device only. It makes no network requests, and it stores only counters and per-site settings.

Private by design

Everything happens on your device. Page content is read only to find banners and popups, and is never stored or sent. There are no ads, no tracking and no accounts, and the extension makes no network requests. It is open source, so you can check for yourself. Read the full privacy policy.

Install

Quiet Web will be available from the Chrome Web Store. Developers can already load the source unpacked from GitHub.

Support

Quiet Web is free. If it helps you, you can optionally make a one-time contribution, or support it monthly, through Stripe. The option appears only at milestones of annoyances handled, and you can turn it off at any time.
